# 水电站机组运行检修管理平台

面向电站台账、机组运行、调速励磁、主变与闸门、大坝渗流位移监测、机组检修与发电计划的一体化水电站运行检修管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydropower-plant-om:entries:v2` 这一项，或调用 `resetModule(模块)`。
  旧版 `hydropower-plant-om:entries` 首次打开会自动迁移（导轴承按检测日期整体回填登记时间，
  早期缺下导温度的保留空值并加备注，在册结论不改写）。

## 导轴承批量标记与对账口径

- 等级划分沿用且只顺向流转：**正常 → 温度偏高 → 待检修 → 已检修**，不回退、不跳级。
- 大负荷后在导轴承页整组勾选、一次「批量标记偏高」，服务端逐台给出结果：
  - 成功：仅「正常」轴承转「温度偏高」并进入检修待办；
  - 跳过：已是「温度偏高」的在册结论，不重复标记、不重复计数；
  - 失败：「待检修 / 已检修」在册结论不可改写，或记录查不到，逐条写明原因。
- 每次批量是一个不可变结论版本（V1、V2…），**最新批次为当前生效结论**，历史版本只读；
  新版本不改写已在册结论。同一批勾选重复提交命中幂等键，只回放首次结果、不再加台数。
- 对账口径只有一份（`bearingReconciliation()`）：导轴承列表卡片/页脚、检修班组页待办、
  备品备件页待办、导出 CSV 的汇总段全部读它。检修待办口径 = 温度偏高 ＋ 待检修，
  备件待办是同口径的只读投影（`bearingSpareDemands()`），任何入口都不另存副本。
- 历史记录按检测日期升序、以检测日期回填登记时间；早期只记上导温度、没记下导温度的，
  **不臆造补值**，保留空值、在「下导温度」列显示未记录，并在页面与导出中另列一行说明。
- 导出的导轴承清单：明细（按检测日期）＋ 对账汇总（各等级台数、待办合计、当前版本）
  ＋ 早期缺项说明一起输出，另存文件里的偏高台数与页面一致。

## 岗位与写权限

顶栏可切换岗位，写接口在服务层强制校验，归属之外的越权改动一律拒绝、其余岗位只读：

| 岗位 | 可写模块 / 动作 |
| --- | --- |
| 运行值班员 | 导轴承：提交检测、批量/单条标记偏高 |
| 检修班组 | 机组检修工作票；导轴承待办：接收检修（温度偏高→待检修）、办理完工（待检修→已检修） |
| 仓库管理员 | 备品备件：验收、领用、补充（轴承备件待办为只读投影） |
| 其他岗位（只读） | 全平台仅查看，任何改动都会被拦截 |
